# Keyboard shortcuts

On macOS the modifier is ⌘. On Windows and Linux use Ctrl in its place.

## Navigation

| Shortcut | Action |
|---|---|
| ⌘/Ctrl+1 | Home |
| ⌘/Ctrl+2 | Pull requests |
| ⌘/Ctrl+3 | Tickets |
| ⌘/Ctrl+4 | Slack (when the module is on) |
| ⌘/Ctrl+5 | Automations (when the module is on) |
| ⌘/Ctrl+6 | History |
| ⌘/Ctrl+7 | Flow maps (when the module is on) |
| ⌘/Ctrl+8 | Health (when the module is on) |
| ⌘/Ctrl+9 | Plan (when the module is on) |
| ⌘/Ctrl+0 | Sessions |
| ⌘/Ctrl+, | Settings |
| ⌘/Ctrl+K | Command palette: type to find a session (by name, folder or state), a screen, **New session** or a Settings section or setting; ↑/↓ choose, Return runs, Esc closes |

## Sessions

| Shortcut | Action |
|---|---|
| ⌘/Ctrl+T | New session with the profile's preferred agent |
| ⌘/Ctrl+L | New session with the first agent in the File menu |
| ⌘/Ctrl+Y | New plain shell session |
| ⌘/Ctrl+Shift+N | Open the session in a new window |
| ⌘/Ctrl+Shift+W | Close the session |
| ⌘/Ctrl+Alt+1 / 2 / 3 | Show as App / Show as Console (Terminal) / Show as Shell |
| ⌘/Ctrl+Alt+↓ / ⌘/Ctrl+Alt+↑ | Next / previous session, in sidebar order (wraps around; sessions in folded groups count) |
| ⌘/Ctrl+J | Next session that needs you (a question or permission waiting, an unread reply, a failure); press again to cycle through them |
| ⌘/Ctrl+Shift+A | Answer the session's pending permission request or question: the focus moves to the oldest one |
| 1-9 | With the focus on a permission request, pick its first, second… button |

## Composer

| Shortcut | Action |
|---|---|
| Return | Send |
| Shift+Return | New line |
| Esc | Interrupt the agent |
| ↑ | In an empty composer, or with the caret on the first line: the session's previous prompt (up to the last 50) |
| ↓ | While going through earlier prompts: the next one, then back to what you were typing |
| Esc | While going through earlier prompts: back to what you were typing |
| Paste | Attach images |

## Other

| Shortcut | Action |
|---|---|
| Alt+↑ / Alt+↓ | Move the focused session or group up or down in the sidebar (also in its row menu) |
| ⌘/Ctrl+Return | Send all comments, in the **Review changes** window |
| ⌘/Ctrl+Alt+. | Stop reading aloud |
| Esc | Leave selection mode in Health |
| Reload | View menu: reloads the window. Workhub also does it by itself if a window crashes; your sessions keep running and their chats come back |
| Zoom | View menu: reset zoom, zoom in, zoom out, full screen |

The key assigned to **New {agent} Session** in the File menu follows the agent order; only the first
agent gets ⌘/Ctrl+L.
